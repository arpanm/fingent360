## Definition of done

Document the contract and behavior; add meaningful failure-path and domain-invariant tests; run relevant repository checks; inspect visible UI changes; record actual verification and limitations. Never expand scope to another asset, paid source or infrastructure component merely because its placeholder exists in the blueprint.
