# CCIL indicative yield source specification

Authored 2026-09-15; deterministic validation and source activation remain manual.

The original public HTML at https://www.ccilindia.com/web/ccil/tenorwise-indicative-yields was fetched for read-only research (HTTP200,145477 bytes). Its `dtTable` has exactly Date, Tenor Bucket, Security and YTM (%) columns. Original dates are `YYYY-MM-DD 00:00:00.0`; values have variable decimal precision. The page explicitly distinguishes T-bill/SDL primary-market cutoffs from other indicative benchmark yields. No ISIN, executable quote, clean price, credit rating, coupon schedule or bond face value is provided. This adapter must not manufacture those missing fields, interpolate a zero curve, or feed them as priced holdings into calculators.

The MTM page describes clean prices and links a workbook through a sign-in-gated download. That workbook was not downloaded through a bypass. NSE's official debt reports and CBRICS page were researched, but current representative security-price bytes remain unverified. SRC018 corporate bond/rating coverage therefore remains pending independently of this source.

CCIL's page explicitly requires written permission for commercial data use. Default `CCIL_ENABLED=false` means no provider fetch and no public distribution. An operator must configure the actual deployment permission reference and enable the source only when retention and intended web/APK redistribution are covered. This is an activation input, not a claim that research created permission. Operations import/fetch is also gated; source history can still be withdrawn while disabled.

Acceptance: strict original table/header/date/tenor/category parser; bounded inert HTML only, no scripts/links executed; immutable raw SHA256 retention, quarantined malformed captures, independent named publish/withdraw review with reconstruction from retained bytes; explicit source-only identities and yield convention; dated history/current reader with ambiguity, stale, loading/empty/error/retry states; shared Android snapshot with capture date and no offline review; exact-source evidence via protected download; synthetic API/browser/offline cases. No derived numerical calculation, new credential handling or scheduler is applicable to this initial manually reviewed source adapter.

## Implemented workflow and manual handoff

`GET /api/v1/bond-yields` and `/snapshot` return only independently published editions whose retained permission reference matches the current enabled deployment. Source disablement removes public admission. Unrelated quarantined/draft captures cannot consume the public history bound. Multiple editions for one date remain separately visible; the reader does not silently pick a corrected yield. Four calendar days is an explicit display-age warning, not a claimed trading-day freshness guarantee.

Protected `/api/v1/ops/bond-yields` provides capture, original evidence download, review and withdrawal. Downloads use `.txt`, never executable HTML. A different named reviewer must publish. SHA256 and reparsed canonical data must match the immutable capture. Migration095 adds source editions and append-only review receipts; MongoDB reuses the existing source raw store. No market values or copied original source data were committed; synthetic fixtures reproduce structure and conventions only.

Android shares `CcilYieldsReader`; `bondYields` is an admitted dated bundle snapshot. A disconnected device cannot learn later permission changes/withdrawals until a refreshed package/snapshot, so it never calls this a live quote. Source capture/review is denied offline.
