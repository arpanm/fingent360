# Source-bound application classification crosswalk

Authored2026-09-15 for SRC-006. Migration077 stores immutable source-bound mapping revisions and independent review receipts. A current admitted equity `classification` observation is required: source edition/hash, ISIN, exact provider label and effective date. A preparer enters the separate application sector, mapping rationale and review-by date. A different named publisher may publish/withdraw; legacy shared credentials cannot provide independent review. A new draft removes its prior public mapping until reviewed. Conflicting active mappings are displayed together rather than silently choosing a sector.

The existing constituent CSV supplies one provider `Industry` label. The [official taxonomy](https://www.niftyindices.com/resources/industry-classification) has four levels. We do not invent official macro/sector/industry/basic-industry codes from that single label. This crosswalk is explicitly an application interpretation; a complete official company assignment requires corresponding authorized dataset evidence. Source rows retain their original provider label and rights metadata in existing equity storage.

Operations: **Classification crosswalks** → enter ISIN → load admitted classifications → select exact row → draft → independent review → history/withdraw. Company reading shows current mappings and source links. `/api/v1/ops/classification-crosswalks` supports paginated100-row queue, PUT `/:id`, POST `/:id/reviews`, GET `/:id/history`; `/api/v1/classifications/:isin` is a public source-admitted projection, and `/api/v1/classifications` supplies a bounded1000-company snapshot. History exposes latest100versions/reviews. Expiry, unavailable/withdrawn source, changed exact record and future effective dates fail current admission. Storage errors are not converted into fabricated empty values.

Android uses shared components and downloaded classification snapshots. Device operations are unavailable; read projections re-admit exact source records from the installed equity snapshot. Offline cannot know later server withdrawals; newer snapshot deployment is required. No automatic source request or licensed-data scraping was introduced.

## Source-rights input and remaining history

[BSE Indices terms](https://www.bseindices.com/terms-of-use) also apply separately. Public access is not the needed distribution agreement. Root asked whether an existing NSE/BSE agreement covers server storage, display and offline distribution; no answer was available during authoring. Default activation remains off without that evidence.

Broader index levels/constituent history and complete official classification assignments remain pending licensed source files/formats and rights. Search results showing third-party CSV layouts were not accepted as primary provider format verification. Historical constituent snapshots are not recreated from today's membership. Adjusted company-price work belongs to the separate076 adjustment workflow; it is not incorrectly part of this classification crosswalk's completion claim.
