## Implemented read and ingest path

GET `/api/v1/discovery/catalog` reports fixed source rights/access and actual published counts, latest publication and last durable check/success. GET `/api/v1/discovery/feed` accepts q/kind/source/topic/region/view plus cursor; Today uses the shared bounded diversified selection while Explore retains all matching published content. GET `/api/v1/discovery/items/:id/context` returns deterministic labelled related evidence/terms/learning from the published collection. Operator POST `/api/v1/ops/discovery/refresh` keeps `{}` compatibility and accepts an optional unique enabled `sourceIds` list; arbitrary URLs/blocked sources are rejected. Operator GET `/api/v1/ops/discovery/runs` returns durable per-source outcomes from additive migration 015. Each source commits independently, failed sources preserve earlier editions, and interrupted running rows become failed on the next refresh. Raw ECB/Fed RSS, PIB index/releases and World Bank JSON are retained in Mongo; no HTML is rendered or executed.

Extra World Bank indicators are India unemployment (`SL.UEM.TOTL.ZS`, modeled ILO estimate, percent labor force), trade (`NE.TRD.GNFS.ZS`, percent GDP), and net FDI inflows (`BX.KLT.DINV.WD.GD.ZS`, percent GDP). Up to twelve annual observations per indicator are stored as versioned drafts with exact source values/units and dates. Existing GDP/CPI observations are synchronized from canonical macro history. This does not implement security prices, company news or current-month macro releases. New provider documents and eight additional sourced educational terms all require review before publication.
