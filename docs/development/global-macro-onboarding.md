## Primary-source research and access boundaries

- [ECB SDMX API](https://data.ecb.europa.eu/help/api/data) documents the fixed data-service format; [ECB disclaimer](https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html) governs attribution/reuse. No universal numeric request allowance was verified in this documentation; do not promise unlimited access. Existing refresh/review/error retention controls remain in force.
- [BLS API FAQ](https://www.bls.gov/developers/api_FAQs.htm) distinguishes registered versus unregistered request budgets. Those JSON API budgets do not establish RSS/ICS limits. This selection uses fixed first-party CPI RSS/ICS, not the optional keyed numerical API. [BLS copyright guidance](https://www.bls.gov/opub/copyright-information.htm) and [calendar instructions](https://www.bls.gov/help/hlpical.htm) are the actual source evidence. Calendar schedules enforce a minimum60-minute application interval; it is not a provider-approved quota.
- [BEA API guide](https://apps.bea.gov/api/_pdf/bea_web_service_api_user_guide.pdf) documents keyed numerical API throttling. The selected headline/calendar adapters do not invoke that API or infer its permissions for other endpoints. Existing BEA first-party headline/rights documentation applies.
- [Federal Reserve disclaimer](https://www.federalreserve.gov/disclaimer.htm) permits reuse of Board text subject to third-party exceptions; logos/images are not included in this text ingestion permission. Historical statement metadata and actual ranges remain explicitly historical.
- **FRED remains an optional, unimplemented candidate.** [Current FRED terms](https://fred.stlouisfed.org/legal/terms/) include restrictions on AI-system usage and third-party content; [API key requirements](https://fred.stlouisfed.org/docs/api/api_key.html) require registered keys. Do not route FRED content into enrichment/evaluation merely because its website is accessible. Direct original-agency sources are the current selection. No FRED key or user decision is needed for those existing direct sources.
- Treasury numerical series and paid data providers remain optional expansion, not falsely implemented adapters. Original historical numerical vintages and calibrated India-impact policies remain separately tracked research requirements.
