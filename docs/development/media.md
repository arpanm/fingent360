# UX-002 source-based media

This deterministic media path generates an actual SVG illustration and timed caption script from a published discovery item's title, summary, source and exact edition. It adds no market figures, invented scenes or provider images. Visuals are explicitly illustrations, not photographs of documents. Source identifiers and the original source URL travel with each artifact. Optional OpenAI, Gemini or Anthropic assistance selects validated complete source blocks before rendering; without a configured provider it uses the source template. Neither path invents event imagery.

Migration013 stores immutable source-version-bound artifacts and append-only operator publication reviews. Generate is idempotent per source edition; draft artifacts remain private until operator review. Public retrieval checks the current published source edition every time; source withdrawal or a reviewed replacement makes an older artifact unavailable. An unreviewed draft correction retains the previous public edition and matching visual. Re-reviewing source metadata creates a new edition and requires a new visual/review. HTTP sessions/origins and audit use the existing operations boundary.

MediaController/OpsMediaController and mediaProvider(config) are registered; shared media contracts validate responses and MediaSummary renders inside the reader. Operations UI calls POST /ops/media/:itemId with {} to prepare, GET to preview, and PUT with assetId/publish boolean to review. Public GET /discovery/items/:itemId/media returns only a reviewed matching asset. Missing media is a normal empty state. No new package dependency is required. Optional provider keys/models use the server configuration described below.

The reader shows the real persisted illustration, manual Play/Pause captions and always-available transcript. Nothing autoplays, including reduced-motion mode. Download caption video explicitly records a local canvas stream using MediaRecorder and downloads a genuine WebM blob with source captions/attribution. The clip has no audio. This is a caption video, not AI footage or a hosted video service. Unsupported browsers show an honest message; no external request or upload occurs during recording. Keep the tab open while generating the short clip. Browser background throttling can lengthen export time.

Manual verification prerequisites: configured operator key, published discovery glossary/news entry, migrations013–014, API/web/DB running. Run format/check then API160 and WEB160 in API/desktop/mobile projects with watch mode off. Unit tests verify XML escaping and exact source binding. API covers idempotency, review gate and withdrawal propagation. Browser covers visible illustration, keyboard/manual captions, transcript and real download where supported; unsupported branch confirms feedback. Also manually play the downloaded WebM and inspect narrow viewport/transcript. Existing source publication/withdrawal tests remain applicable. Inspect artifacts/e2e/latest.md for failures. See [current verification](status.md) for executed integration evidence.

## Optional provider-assisted caption selection

Operator Prepare may use the configured OpenAI, Gemini or Anthropic provider/model through the same server-only configuration as field assistance. No model defaults are inferred. The model only selects complete bounded blocks from the approved source edition; source ID/version and every block are validated before rendering. Invalid or unavailable responses produce the deterministic template instead. This remains a source-based SVG and caption/WebM template, not cinematic AI video or a photograph of an event. Preparing never runs during reader requests.

Asset JSON now reports `generation.provider`, `generation.model` and `generation.fallbackReason`; legacy assets default to template/null metadata. Rendering/review endpoints and their request bodies are unchanged. Source/title/attribution remain fixed to the original item edition.

Additive migration014 records a unique preparation attempt per source edition without modifying immutable migration013 assets. Preparation reserves that attempt under a PostgreSQL advisory transaction lock before the bounded provider request. Concurrent preparation returns409; subsequent preparation reuses the existing asset without another provider call. An interrupted attempt with no asset becomes a template fallback after30seconds, with no charged retry. Operator Prepare for a new source edition is a separate explicit action. Per-process limits permit two concurrent media provider requests and20 attempts/minute; provider-account spend controls remain necessary across multiple processes.

Unit fixtures validate complete source blocks, edition binding and concurrent/repeated prepare request reuse without network calls. Manual acceptance: inspect actual provider/model metadata after deliberately preparing a new edition with a configured provider; missing/invalid provider configuration must report template/fallback instead of claiming AI generation. Only reviewed assets become public. See [current verification](status.md) for runtime evidence. Live paid-provider validation remains pending configured keys/models.

Provider caption selection now uses only complete title, summary or body fields of 8–240 characters, supplied as an explicit block list. It may order/select blocks but cannot trim them or remove a qualifying sentence. The combined selected text is limited to 240 characters to keep all selected context in the renderer; oversized or invalid selections use the deterministic template fallback. Unit cases reject negation stripping and truncated long blocks.
