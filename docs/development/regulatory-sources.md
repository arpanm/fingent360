# Regulatory and tax original-source registry

Authored 2026-09-15; no gates, service runs or migration execution. This registry completes original capture → retention → independent editorial review → versioned public/shared-app reader → offline snapshot for the supported primary authorities. It does not decide legal applicability, compute new tax policy, certify complete legislation coverage or activate regulated advice.

## Primary research and source rights

- SEBI: the [November2025 IA regulations index](https://www.sebi.gov.in/legal/regulations/nov-2025/securities-and-exchange-board-of-india-investment-advisers-regulations-2013-and-securities-last-amended-on-november-25-2025-_98246.html) and [February2026 IA master circular original PDF](https://www.sebi.gov.in/sebi_data/attachdocs/feb-2026/1770375291405.pdf) are original candidates. Its published [website policy](https://www.sebi.gov.in/hindi/website-policy.html) requires obtaining permission, accurate context and attribution; third-party material is excluded. No permission mail was sent or approval assumed.
- RBI: [official KYC original PDF](https://www.rbi.org.in/commonman/Upload/English/Notification/PDFs/MD18KYCF6E92C82E1E1419D87323E3869BC9F13.pdf) and [official notification10292](https://www.rbi.org.in/scripts/NotificationUser.aspx?Id=10292) demonstrate original formats and amendments. Indexed versions differ in their update dates; no latest-effective claim is inferred from crawler dates. A broad reproduction permission was not established in this research; exact document/deployment rights must be recorded before retention activation.
- Income Tax: [new capital-gains FAQ original PDF](https://www.incometaxindia.gov.in/documents/20117/14614766/FAQs%2B-New-Capital-Gains-Taxation-regime.pdf/ad59d362-7bce-f0aa-e483-ce0f61ac13d6?t=1767816817352) is a dated explanatory source, not a complete current tax applicability assessment. The [e-filing portal copyright policy](https://www.incometax.gov.in/iec/foportal/using-the-portal/webSitePolicies) allows accurate contextual reproduction with attribution, excluding third-party material. That policy is not automatically extended to another department host or unrelated content; record the actual scope.
- Finance Ministry: [Budget2026 Finance Bill PDF](https://www.indiabudget.gov.in/doc/Finance_Bill.pdf) and [explanatory memorandum PDF](https://www.indiabudget.gov.in/doc/memo.pdf) are original proposals. Their title does not establish enactment or common commencement date. The [DEA website policy](https://dea.gov.in/index.php/hi/node/99) requires permission and attribution; it is not assumed to grant rights for every Finance Ministry host. Exact Budget-host/document rights remain activation input.

Source bytes are not bundled or committed as copyright fixtures. Tests contain small clearly labelled synthetic documents. No provider response is executed or treated as policy instructions. Existing [operating-model research](advice-applicability.md) remains the separate DEV-013 input record.

## Data and workflow

Migration101 stores immutable source editions and append-only review events in PostgreSQL. Original bytes are base64-retained in the existing Mongo raw store under a namespaced key; SHA256 is computed over decoded original bytes, not a normalized page. MIME, original URL, acquisition method, retrieval and recording timestamps, jurisdiction/scope, document key, predecessor and rights references are retained. A server fetch is bounded1.5MB with exact official-host HTTPS admission, no redirects/cookies and exact expected HTML/PDF MIME. Alternatively an editor uploads unchanged original bytes with explicitly declared retrieval time. Import source provenance is editorially reviewed, not falsely labelled server fetched.

HTML/PDF envelope checking is deliberately not a regulatory parser. A malformed envelope quarantines the capture. Dates are annotations with explicit unknown/year/month/day precision and a page/paragraph evidence locator; no midnight timestamp, effective date or enacted status is invented. Publication requires a different named reviewer, original inspection/rights acknowledgement and review-by date. Request replay uses stable fingerprints; changed evidence cannot overwrite an edition. A successor explicitly names its same-authority/document predecessor. Published predecessors receive immutable supersession events; withdrawing a successor never automatically revives a predecessor. Republish requires a new revision.

Operations has individual source fields, upload/fetch, original inspection, rights display, independent publish and withdrawal, error/retry and25-record continuation. The reader at `#regulatory-sources` has authority/text filters over loaded pages, explicit historical mode, expandable originals/dates/scope/hash, overdue review warning and source links. Current and historical reads paginate25 records with keyset cursors. Offline snapshots include only currently published/overdue-review records, never draft/quarantine or superseded/withdrawn records; more than100 current records refuses an incomplete snapshot. A previously downloaded copy cannot learn subsequent withdrawal until refresh, and visibly makes no current-legal-status claim. Android/iOS reuse the shared reader; rebuild/reinstall bundled offline assets to receive a new edition. No local source mutation is allowed.

Private rights references and named editorial audit data stay in Operations. Public records always carry `applicability:not-assessed` and `adviceEnabled:false`. No LLM calls or finance calculations are introduced. Capture is user/operator initiated; automated legal interpretation or automatic source publication is not enabled.

## Manual activation and validation

Provide genuine deployment/source rights in server-only REGULATORY_SOURCES_PERMISSION_REFERENCE, enable REGULATORY_SOURCES_ENABLED only for that approved scope, then apply migration101 via the documented migration command. Keep unrelated sources disabled until their permission review. Missing private input remains the operating entity/qualified legal review under DEV-013; it does not prevent registry authoring.

With repository dependencies and PostgreSQL/MongoDB available, run `pnpm sdlc "Add reviewed regulatory source registry" --grep 'E2E-(API-168[0-5]|WEB-168[0-2]|OFFLINE-1680)'` manually. No npm dependency was added. API1680–1685 cover strict host/precision, disabled gate, actual bytes, independent review, replay, quarantine, supersession and withdrawal; WEB1680–1682 cover connected public reader and actual Ops fields; OFFLINE1680 covers stale-date treatment/no local mutation. In Operations choose Regulatory originals; public URL is the current dev URL with `#regulatory-sources`. Test UI uses its printed URL with watch off. Share failing run/case/artifact paths and redacted error, not private permission correspondence. Physical keyboard/mobile/source-link and offline refresh acceptance remain manual. No test pass or activation is claimed; local HEAD a2c53a0 and all shared modifications await user-run gated commit.
