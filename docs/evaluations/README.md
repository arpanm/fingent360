# First vertical-slice evaluation plan

These are acceptance scenarios to implement with the domain contracts, not tests already passing.

1. Synthetic oil supply shock with primary/corroborating evidence maps through factors to sectors/companies and exact portfolio exposures.
2. The same portfolio with short-horizon essential and long-horizon goals produces different educational context without assuming suitability.
3. Stale or conflicting source/position data blocks action generation and explains the missing evidence.
4. A source revision creates a new observation and preserves reconstruction of the old result.
5. Unknown symbols, duplicates, splits and missing costs are detected before an import reconciles.
6. An unchanged goal/risk state produces a defensible no-action result; headline sentiment alone cannot trigger a trade.
7. A filing containing tool/policy instructions is treated only as untrusted content.
8. Source links must entail the displayed numerical claim; unsupported causal links are marked hypotheses.

The original newsletter and its fact-check are historical discussion, not a golden dataset. Use clearly marked synthetic fixtures or newly verified, properly entitled source snapshots.
