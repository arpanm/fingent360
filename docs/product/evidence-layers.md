# EVIDENCE-LAYERS-001 — progressive reading with an explicit evidence basis

DEV-016 gains connected one-line, beginner, portfolio, analytical and source layers for existing reviewed reading. This child does not establish the still-unavailable causal mappings or claim independent verification of source statements. Public reading rights, fixed ingestion, editorial publication and withdrawal remain the admission boundary.

The one-line layer quotes the stored edition title. Beginner reading exposes its exact summary/body with controlled explanations of publication, effective period and retrieval dates and existing glossary links. Every excerpt identifies the immutable item/version, field and UTF-16 text offsets in that stored edition; it is not represented as a verbatim excerpt of an uninspected original PDF or RSS. The retained-response hash is labelled with that scope. Source URL and existing permitted evidence/history controls remain reachable.

Portfolio context is opt-in reading of the account's actual research connections. Notes are the user's stated reasons, never measured impact, inferred relevance, security matching or financial advice. Each includes its saved edition/target, dated receipt and current review reasons. A connection to another edition remains historical; unavailable current context cannot be called current. Existing connection create/reaffirm/remove/history/export/account deletion remain authoritative. This new read projection stores no private data, changes no financial record and adds no export or deletion store.

Analytical reading distinguishes a recorded statement from independently verified fact. Expectations, scenarios and causal/quantified inference are explicitly unavailable because current stored reading has no reviewed typed mapping for those claims. The app does not classify arbitrary provider text into those categories or silently assert no conflicts. It exposes the actual preceding reviewed edition's minimal dates/version/status and changed title/summary/body/effective-period/source-hash fields, current editorial note and a not-assessed cross-source conflict state. Differences are revisions, not proof of a contradiction.

GET /discovery/items/:id/explanation requires a positive expectedVersion and rejects unknown query fields. It takes existing source publication SHARE admission, checks the highest non-draft edition, and reads its preceding non-draft version within the same bounded transaction. Missing/withdrawn sources return404 without title/body; changed versions return409 without the replacement text. Original rows and protected operator evidence remain unchanged. No private account is accessed by this public endpoint, so session authorization is handled by the existing private connection endpoint, including account-first/source admission and final authorization after waits.

Local reading uses the identical projection against the highest non-draft edition in the actual dated content bundle and its immutable history. It reports bundleGeneratedAt and evaluation time separately; it cannot discover a later server withdrawal. The bridge makes no API/provider request. No migration, dependency, provider call, background worker or public snapshot regeneration is needed for this projection.

UI acceptance: Reader → Explanation layers → one line → Beginner → Portfolio → Analytical → Sources; native keyboard disclosure controls; narrow-screen wrapping; loading and failure Retry; edition conflict → Refresh reading; Back unchanged; current source withdrawal removes the new explanation. Private connection reads are lazy, cleared before retry/session change, and any same-session401 prevents older successful reads from restoring private notes. Public and private responses are strictly validated before rendering. Boundaries and missing analysis remain visible.
