# STORY-MEDIA-002 — useful story space and reviewed illustration

Stories use their content area as the vertical swipe surface; Previous/Next and keyboard arrows remain. Reading retains left/right preference gestures and explicit preference buttons. A small animated overlay teaches each gesture context once per document lifetime, dismisses after 6.5 seconds, and supports Got it/Escape. It never captures focus or blocks reading. Reduced-motion users get the same written instruction without movement. Reload makes guidance available again. The large repeated arrows/glyph and instruction panels are removed.

Reviewed images replace the news-arrow decoration. If no reviewed generated image exists, Stories show source text without claiming a photo/illustration exists. Existing caption visuals remain available within detailed reading. Errors expose explicit retry. No LLM, credential or provider request runs from consumer React.

Operations can explicitly prepare one conceptual image for a retained published source/asset using OpenAI or Gemini. The server constructs a bounded public-only prompt; source text is untrusted context. Fixed provider endpoints accept no external URLs. PNG response bytes, prompt, provider/model, source-bound asset ID and complete successful provider output are retained in PostgreSQL. Ten attempts/hour database-wide and one active generation limit cost. Explicit request IDs prevent duplicate paid calls after lost replies; failed/interrupted IDs require explicit new attempts. No hidden regeneration loop.

Image publication reuses the existing media review, including independent named-operator approval. The exact image attempt ID must match the review request, preventing a later replacement being approved by an earlier review. Source changes during generation preserve output for audit but do not expose it on the changed source. Unreviewed images never enter public snapshots. Shared Android snapshots retain admitted base64 bytes and work without a network; rebuild/reinstall is required. AI images remain visibly labelled conceptual and are never presented as event evidence. Provider/account access and model rights require deployment configuration; no generated bytes are fabricated during authoring.

## Official provider references

- [OpenAI image generation](https://developers.openai.com/api/docs/guides/image-generation), inspected 2026-09-14: Images API generations and base64 PNG output. Default model gpt-image-1, optional explicit configured override.
- [Gemini image generation](https://ai.google.dev/gemini-api/docs/generate-content/image-generation), inspected 2026-09-14: generateContent image output in inlineData. Default gemini-2.5-flash-image; configured model may be changed without browser exposure.
- Anthropic is not selected as an image generator. Its existing text/caption capabilities are unchanged. This feature delivers generated images, not provider-generated video; existing caption-video export remains explicitly a text-caption clip.
