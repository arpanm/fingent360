Status: initial25-company two-metric acceptance cohort authored; user validation pending. Source inspection15September2026. Parent [SRC-005](SRC-005.md).

The original acceptance explicitly requires selecting an initial financial schema and25-company validation set. No such manifest existed; earlier synthetic cases and three industry examples did not satisfy this authoring requirement. This work selects25 distinct IndAS issuers from the official NSE Integrated Filing – Financials table, and independently reads their displayed ISIN, period, basis, audit, currency, scale, revenue and total profit/loss. ## Acceptance and implementation prompt

Use `tests/e2e/fixtures/equity-company-cohort.json` with25 independently inspected original report links. Keep the original displayed amounts and two source columns distinct from separately authored normalized expected outcomes. Reconstruct only the verified rendered grammar; do not claim original HTTP byte fixtures, official licensing, publication timestamps or live validation. Bind each expected amount to exact ISIN, start/end, basis, INR scale and audit status. Include losses, zero revenue, standalone/consolidated, distinct quarter/YTD and duplicate first-quarter/YTD.

The research exposes two defects in the existing v1 rendered adapter: legitimate Indian comma groups (e.g. Gokul Agro462494.57 displayed4,62,494.57) were rejected, and identical quarter/YTD observations were emitted twice under the same database key. Fix only these exact behaviors: admit validated Western or Indian grouping, never arbitrary commas; compare complete duplicate observation facts and retain one only when semantically equal, rejecting contradictory columns. Reuse existing immutable original retention, API, company/history reader, shared Android and offline contracts; no new database or UI surface required. Author API1890–1892 covering the full cohort, retention/publication of duplicate-period input, and conflicting/malformed rejection; shared reader/offline cases must preserve exact loss and scale. Do not run gates or provider jobs.

Remaining validation: the user must run saved gates/cases and, under actual source rights, inspect retained originals. The selected cohort covers the initial two IndAS income metrics; it does not prove25-company balance-sheet/cash-flow, bank or insurer coverage, all-company coverage, or independent exchange-to-issuer reconciliation.
