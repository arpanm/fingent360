## Completion specification — 2026-09-15

This task implements curated market/company news onboarding, not unrestricted paid feeds. Every report links a reviewed Indian-company ISIN; has original editorial title/summary; has at least two independently originated sources, including an issuer/regulator/filing primary source; and records the editor's claim-by-claim corroboration and conflict/staleness review. Two exchange mirrors or syndicated copies of one release count as one originator. Unknown/contradicted/stale evidence stays draft. Exact URLs, publication/retrieval times and rights decisions are retained; no remote content is automatically fetched by this workflow.

Link-only mode forbids copied article text/media. It still requires source-specific linking permission, because [NSE's hyperlink policy](https://www.nseindia.com/static/hyperlinking-policy) requires prior written permission. Full-text mode requires explicit evidence covering storage/display and offline redistribution; sources with expiry or unsupported scope cannot be admitted through this first policy version. [PIB copyright policy](https://www.pib.gov.in/content/3604_2_CopyrightPolicy.aspx?lang=1&reg=3) permits accurate attributed first-party reproduction but excludes third-party material. [Reuters transactional terms](https://www.reutersconnect.com/transactional-license-terms) depend on the order/license and source notices; no Reuters entitlement is assumed or acquired.

Implementation acceptance: strict source/verification contracts → immutable DB input/review and raw evidence → prepare/review/withdraw API with named separation of duties → Operations form and normal Today/Stories publication → public company/source verification panel and offline proof → API/browser/offline cases. Generic discovery review must not bypass company-news checks. The application must never call a link-only citation 'full text' or claim algorithmically established source independence: two-person recorded review is the basis. Rejected preparation/review must not publish. A source permission withdrawal uses normal immutable withdrawal and the existing connected/bundle publication manifest; an already disconnected app learns withdrawals only when refreshed, as with other feed sources.

No new user question: public terms researched by agent; private license evidence is entered only by an authorized operator when activating that source. Implementation can complete without fabricating permission. Paid procurement and live source/provider acceptance remain separate.
